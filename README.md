# ✨ GestureCam Pro – AI Hand-Controlled Camera

GestureCam Pro is a real-time, AI-powered camera application that allows users to control camera zoom, pan, and other functions using simple hand gestures.

Built with **HTML, CSS, JavaScript, and MediaPipe Hands**, this project uses hand tracking technology to create an interactive, touch-free camera experience.

## 🚀 Features

- ✋ **Real-Time Hand Tracking** – Detects and tracks hand movements using MediaPipe.
- 🤏 **Gesture-Based Zoom** – Zoom in and out using thumb and index finger movements.
- 👉 **Camera Pan** – Move your hand to control the camera position.
- ✌️ **Quick Reset** – Show a two-finger V gesture to reset zoom and position.
- 👊 **Movement Lock** – Make a fist to freeze camera movement.
- 📸 **Capture Photos** – Capture camera moments and save them as JPEG images.
- 🎨 **Photo Filters** – Choose between four filter modes:
  - None
  - Grayscale
  - Sepia
  - Invert
- 🖐️ **Visual Hand Tracking** – Displays hand landmarks with green dots and connecting lines.
- 🖼️ **Photo Gallery** – View captured photos directly inside the application.
- 🔄 **Smooth Animations** – Smooth camera movement and zoom transitions.
- 📱 **Responsive Design** – Works with different screen sizes.

## 🖐️ Gesture Controls

| Hand Gesture | Action |
|---|---|
| 🤏 Pinch In | Zoom Out |
| 🖐️ Fingers Spread / Pinch Out | Zoom In |
| ✌️ Two-Finger V | Reset Zoom and Pan |
| 👊 Make a Fist | Lock Camera Movement |
| 👉 Move Your Hand | Pan Camera |

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling, responsive layout, and animations.
- **JavaScript** – Camera controls, gesture logic, and photo processing.
- **MediaPipe Hands** – Real-time hand detection and landmark tracking.
- **HTML5 Canvas** – Drawing hand landmarks and processing captured images.
- **WebRTC** – Browser camera access through the MediaPipe camera utilities.

## ⚙️ Installation & Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/GestureCam-Pro.git
   ```

2. Open the project folder:

   ```bash
   cd GestureCam-Pro
   ```

3. Open the project using **VS Code**.

4. Run the project using the Live Server extension.

5. Allow camera permission when your browser requests it.

6. Show your hand in front of the camera and start controlling it!

## 📸 How to Use

1. Launch GestureCam Pro in your browser.
2. Allow access to your webcam.
3. Place your hand in front of the camera.
4. Use the supported gestures to control zoom and movement.
5. Click **Capture Moment** to take a picture.
6. Apply different filters using the filter button.
7. Click a captured photo in the gallery to download it.

## 🔒 Requirements

- A webcam or built-in camera.
- A modern web browser.
- Internet connection to load MediaPipe libraries from CDN.
- Camera permission enabled.
- HTTPS or localhost for browser camera access.

## 🎯 Project Objective

The main objective of GestureCam Pro is to demonstrate how computer vision and hand gesture recognition can be integrated into a web application to create a touch-free and interactive camera control system.

This project explores the practical use of AI-powered hand tracking, real-time image processing, and gesture-based human-computer interaction.
